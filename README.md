<details>
<summary><b>🌱 For newbies: how I'd start with AI agents</b></summary>

Ten years of backend taught me that the hard part is keeping software working, not writing it. Agents make writing fast; these habits keep it working:

1. **Understand before you automate**: know *why* something works before asking the agent to do it.
2. **Read the files agents create**: JSON, YAML, Markdown. You can edit them safely without writing code.
3. **Keep your app alive after session one**: git commits as restore points, never paste API keys into chat, let tests and CI check every change.
4. **Give the agent clear briefs**: goal, context, limits, and how you'll check it's done.
5. **Only then let the agent run on its own**, with a goal it has to prove.

</details>
