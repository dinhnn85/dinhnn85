<details>
<summary><b>🌱 For newbies: start where I started</b></summary>

I started without a programming background. If that's you, this is the order that works for me:

1. **Learn how to think with AI first**: understand *why* something works before asking the agent to do it.
2. **Learn to read the files agents create**: JSON, YAML, Markdown. You don't need to write code to edit them safely.
3. **Keep your app alive after session one**: git commits as restore points, never paste API keys into chat, let tests and CI check every change.
4. **Give the agent clear briefs**: goal, context, limits, and how you'll check it's done.
5. **Only then let the agent run on its own**, with a goal it has to prove.

</details>
